# Calculadora Streamlit

Uma calculadora moderna e interativa desenvolvida com Python e Streamlit.

## Funcionalidades

- Operações básicas:
  - Adição (+)
  - Subtração (-)
  - Multiplicação (×)
  - Divisão (÷)
  - Potência (^)
  - Raiz Quadrada (√)
  - Porcentagem (%)

## Características

- Interface web moderna e responsiva
- Botões coloridos e interativos
- Tratamento de erros
- Display com fonte monoespaçada
- Suporte a números decimais

## Como usar

1. Certifique-se de ter Python instalado
2. Instale as dependências necessárias:
   ```
   pip install streamlit
   ```
3. Execute a aplicação:
   ```
   streamlit run calculadora_streamlit.py
   ```
4. A calculadora abrirá automaticamente no seu navegador padrão

## Requisitos

- Python 3.x
- Streamlit
