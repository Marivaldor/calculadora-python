# Calculadora Python

Uma calculadora com interface amigável no terminal, desenvolvida em Python.

## Funcionalidades

- Operações básicas:
  - Adição (+)
  - Subtração (-)
  - Multiplicação (×)
  - Divisão (÷)
  - Potência (^)
  - Raiz Quadrada (√)
  - Porcentagem (%)

## Características

- Interface colorida e amigável
- Tratamento de erros
- Mensagens claras e intuitivas
- Limpeza automática do terminal
- Exibição formatada dos resultados

## Como usar

1. Certifique-se de ter Python instalado
2. Instale a dependência necessária:
   ```
   pip install colorama
   ```
3. Execute o arquivo:
   ```
   python calculadora.py
   ```
4. Siga as instruções na tela para realizar os cálculos

## Requisitos

- Python 3.x
- Biblioteca colorama
